Atención con el formato CBR

Este archivo parece ser un archivo RAR (.cbr) puro. Debido a limitaciones tecnológicas de los navegadores, no podemos descomprimir RARs complejos de forma nativa.

Solución: Te sugerimos usar un programa para convertir tu cómic a formato .cbz (ZIP) o descargar directamente versiones CBZ.
